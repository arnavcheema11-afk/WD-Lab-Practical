# WD Lab Practical — Experiments 1–7

Based on the supplied `WD FILE NEW.pdf`.

## How to run
1. Download/extract this repository ZIP.
2. Open an experiment folder.
3. Double-click its `.html` file, or open it in VS Code and use Live Server.
4. Experiments 6 and 7 include a registration page connected to the relevant JavaScript validation.

## Notes
- The PDF references image files (`logo-2.webp`, `image.jpg`, `aa.jpg`, and `images/cse.png`) that were not supplied separately. The HTML will still open, but those images will not display until you add the matching files.
- A few small corrections were made so the examples run reliably: missing HTML tags were fixed, form names/validation hooks were connected, and the CSS files include the cursor classes used in the sample page.
- Experiment 9 uses the background image URL shown in the PDF and therefore requires an internet connection for that image.
